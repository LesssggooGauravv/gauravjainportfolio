# root@jain — Personal Portfolio

A terminal-inspired personal portfolio showcasing software engineering, AI/ML, speech & audio systems, and edge AI work through an interactive Unix-style desktop environment.

## 🌐 Live

**[View Portfolio](https://gauravjain.is-a.dev/)**

## 🚀 Features

- Terminal-inspired desktop UI
- Interactive boot sequence with fullscreen launch
- Draggable and resizable application windows
- Built-in interactive terminal
- Command-driven portfolio navigation
- Project, experience, education, skills, and contact windows
- Resume download
- Custom animated cursor
- CRT-inspired visual effects
- Responsive layout
- Direct links to GitHub, LinkedIn, LeetCode, and email

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
  - JetBrains Mono
  - Press Start 2P

No frontend framework or build system is required.

## 🖥️ Portfolio Sections

The desktop currently includes:

- `whoami` — personal introduction and engineering focus
- `experience.log` — professional experience
- `projects/` — selected projects and technical work
- `education.md` — academic background
- `skills.sh` — technical skills
- `contact.md` — contact and social links
- `terminal` — interactive command-line interface
- `resume.pdf` — downloadable resume

## ⌨️ Terminal Commands

Open the terminal and run:

```text
help
whoami
about
ls
ls projects
cat <file>
projects
experience
education
skills
contact
resume
github
linkedin
leetcode
email
neofetch
clear
exit
```

## 📦 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/gaurav-jain-portfolio.git
cd gaurav-jain-portfolio
```

No dependencies or build process are required.

Open `index.html` directly in a browser, or run a local development server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🌐 Deployment

The portfolio is designed as a static website and can be deployed on platforms such as:

- Cloudflare Pages
- GitHub Pages
- Netlify
- Vercel

For Git-based deployments, updates can be published by pushing changes to the repository:

```bash
git add .
git commit -m "Update portfolio"
git push
```
